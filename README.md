## Featured Products

### Sole Showdown

A sneaker battle, ranking, collection, and game platform built around an Elo-based voting system.

**Focus:** product engineering · game mechanics · ranking systems · monetization · responsive UI

**Stack:** Next.js · TypeScript · Prisma · PostgreSQL · Redis

---

### X Collector

A Solana wallet hygiene and rent-recovery utility designed to help users reclaim unused account rent while maintaining full control over every transaction.

**Focus:** Solana · wallet utilities · recovery flows · security · mobile dApp UX

**Stack:** Next.js · TypeScript · Solana · Anchor

---

### Hire Horizon

An AI-assisted career and job-acquisition command center for remote professionals.

**Focus:** automation · job intelligence · workflow orchestration · AI-assisted search

**Stack:** TypeScript · Supabase · AI workflows

---

### Artist Arc

A platform for artists focused on professional digital presence, workflow management, and audience growth.

**Focus:** creator tooling · platform design · growth systems

**Stack:** React · TypeScript · Supabase
